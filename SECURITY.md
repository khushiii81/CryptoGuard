# Security Policy

## Supported Versions

Currently, only the `main` branch of this repository is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

Please note that CryptoGuard is an **educational simulator** and does not act as a real firewall. However, if you discover a security vulnerability in the web application itself (e.g., XSS, CSRF, insecure dependencies), please report it to us.

1. Do NOT open a public issue on GitHub.
2. Email your findings directly to the maintainer.
3. Please allow a reasonable amount of time for a response and remediation before publicly disclosing the vulnerability.

We appreciate your efforts in keeping this project secure!
